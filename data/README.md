# 콘텐츠 데이터

이 폴더는 카드, 직업, 의뢰 데이터를 넣기 위한 자리입니다.

- `cards`: 인물, 장비, 소비 카드 Resource
- `jobs`: 직업별 성장치, 최대 10레벨, 습득 스킬, 상위직업 전직 조건 Resource
- `species`: 종족 성장치와 종족 스킬 Resource
- `requests`: 스토리, 일반, 이벤트 의뢰 Resource
- `sql`: 문서 기반 스킬 DB를 관리하기 위한 SQLite SQL 스크립트

스킬 DB는 스킬, 스킬 유형, 해금 직업/레벨만 테이블로 나누고, 스킬 ID는 숫자로 관리합니다.
스킬 유형 ID는 `1`이 액티브, `2`가 패시브입니다.
장비 조건과 사용 가능 열은 스킬 컬럼에서 바로 관리합니다.
`skills.usable_columns`에는 사용 가능한 열만 쉼표로 구분해 입력하며, 나머지 열은 사용 불가로 판단합니다.
예를 들어 `2,3,4`는 1열에서 사용할 수 없다는 뜻입니다. 빈 문자열(`''`)이나 공백은 위치 제한 없이 모든 열에서 사용 가능하다는 뜻입니다.
주 스탯은 `skills.main_stat`에 `힘`, `민첩`, `지능`, `매력`, `체력`으로 입력합니다.
주 스탯이 없거나 아직 정하지 않은 스킬은 빈 문자열(`''`)로 둡니다.
피해 구분은 `skills.damage_type`에 `0`(피해 없음/미정), `1`(물리 피해), `2`(마법 피해)로 입력합니다.
물리 피해는 대상의 방어력(`DEF`), 마법 피해는 마법 방어력(`MDEF`)을 사용하는 구분입니다.
이 열이 없는 기존 DB는 `sql/add_skill_damage_type.sql`을 한 번 실행해 데이터를 유지하며 추가할 수 있습니다.
새 스킬 입력 명령어 양식은 `sql/add_skill_template.sql`을 복사해서 사용합니다.
양식의 스킬 ID를 `NULL`로 두면 숫자 ID가 자동 발급되며, `last_insert_rowid()`로 직업 해금 정보에 연결합니다.

인물 카드의 성장치는 캐릭터 고유 성장치, 종족 성장치, 직업 성장치를 합산해서 계산합니다.
기본직업은 투사, 사수, 마법사, 사제, 첩자, 재주꾼의 6종입니다. 현재 직업의 성장치만 적용되지만,
10레벨을 달성한 직업의 성장치는 다른 직업으로 바꾼 뒤에도 영구 적용됩니다. 직업에서 습득한 스킬도
직업 변경 후 유지되며, 상위직업은 지정된 선행 직업을 10레벨까지 성장시켜야 전직할 수 있습니다.
캐릭터 개인 성장치는 0 없이 10 단위로 배분되며 총합은 100~120입니다. 종족, 직업, 개인 성장치를
합산한 뒤 100으로 나눈 몫이 1레벨 능력치와 레벨업 증가량이 됩니다. 예를 들어 150은 1, 210은 2입니다.

방어력(`defense`)과 마법 방어력(`magic_defense`)은 기본값이 0인 전투용 스탯입니다.
개인·종족·직업 성장치, 최초 능력치, 레벨업 증가량에는 반영하지 않습니다.
장비 카드의 `stats.defense`와 `stats.magic_defense`에 수치를 입력하면 장착 중에만 합산됩니다.
스킬 효과는 `GameState.set_character_skill_bonus_stats(character, skill_id, bonus)`로 적용하고,
`remove_character_skill_bonus_stats(character, skill_id)`로 해제합니다. `bonus`는 `StatBlock`이며,
동일 스킬 ID를 다시 적용하면 기존 보너스를 교체하고, 서로 다른 스킬 ID의 보너스는 합산합니다.
SQL 스킬 DB는 관리용이며 현재 런타임에서 자동으로 읽지는 않으므로, 스킬별 효과를 구현할 때 이 API를 연결합니다.

고용소에는 매일 이름, 종족, 기본직업, 능력치, 개인 성장치, 개인 스킬과 임금이 무작위로 조합된
인물 후보 3명이 등장하며, 고용하지 않은 후보는 다음 날 새로운 후보로 교체됩니다.

새 게임을 시작하면 플레이어 캐릭터 생성창에서 이름, 종족, 기본직업을 정합니다. 개인 성장치는
각 능력치에 기본 10씩 주어지고 추가 80점을 10 단위로 직접 분배합니다. 초기 개인 스킬은 2개를 선택하며, 생성된 플레이어 캐릭터는
임금이 없고 일반 캐릭터와 동일하게 레벨업, 장비 장착, 직업 교육과 전직을 이용할 수 있습니다.

매일 이벤트 목록에는 정보 수집·호위·요인 사살·교섭 중 무작위 일일 의뢰 1개와
거리 공연·행상·일일 아르바이트 중 무작위 일일 소득 1개가 생성됩니다. 미수행 항목은 다음 날 교체됩니다.
