# City of Star

현대식 어반 판타지 사무소 운영 시뮬레이션 게임의 초기 Godot 4 프로젝트입니다.

현재 구조는 매일 의뢰가 발생하고, 인물 카드를 배치해 주사위 판정으로 해결하며, 매주 세금을 내지 못하면 게임 오버가 되는 흐름을 기준으로 잡았습니다.

## 실행

1. Godot 4에서 이 폴더를 프로젝트로 엽니다.
2. `res://scenes/main/main.tscn`을 실행합니다.

## 현재 포함된 것

- 기본 실행 씬
- 날짜, 주차, 자금, 세금 상태를 가진 게임 상태 싱글톤
- 카드와 의뢰 정의용 Resource 클래스
- 매일 무작위로 생성되는 일일 의뢰 1개와 일일 소득 1개
- 인물 배치를 실행으로 확정하고 다음 날 정산창에서 한꺼번에 처리하는 `D6 + 주요 능력치` 의뢰 판정
- 이벤트 배치 전 파란색·배치 확정 후 검은색 발광 표시와 인물 중복 배치 방지
- 대성공(8 이상) 40 money, 성공(6 이상) 20 money, 실패 0 money 보상
- 종족·직업·성장치·초기 스킬을 선택하는 플레이어 캐릭터 생성
- 랜덤 인물 고용과 직업 교육·전직 시스템
- 문서에서 추출한 설계 요약
