# City of Star

현대식 어반 판타지 사무소 운영 시뮬레이션 게임의 초기 Godot 4 프로젝트입니다.

현재 구조는 문서의 핵심 규칙만 코드 뼈대로 옮긴 상태입니다. 매일 의뢰가 발생하고, 카드로 의뢰를 해결하며, 매주 세금을 내지 못하면 게임 오버가 되는 흐름을 기준으로 잡았습니다. 이벤트, 인물, 장비, 소비 카드의 실제 데이터는 아직 만들지 않았습니다.

## 실행

1. Godot 4에서 이 폴더를 프로젝트로 엽니다.
2. `res://scenes/main/main.tscn`을 실행합니다.

## 현재 포함된 것

- 기본 실행 씬
- 날짜, 주차, 자금, 세금 상태를 가진 게임 상태 싱글톤
- 카드와 의뢰 정의용 Resource 클래스
- 빈 콘텐츠 폴더와 자동 로딩 카탈로그
- 문서에서 추출한 설계 요약

## 다음 작업 후보

- 인물 카드 데이터 작성
- 장비와 소비 카드 효과 모델링
- 일반 의뢰 자동 생성 규칙 추가
- 스토리 의뢰 체인과 이벤트 의뢰 재발 규칙 구현
- 의뢰 해결 성공률과 능력치 판정식 설계
