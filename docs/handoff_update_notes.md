# City of Star 인수인계 및 업데이트 노트

작성일: 2026-09-16

이 문서는 현재까지 구현된 구조와 다음 작업 후보를 한곳에 모아두기 위한 작업 노트입니다. 앞으로 기능을 추가하거나 방향을 바꿀 때 이 파일을 계속 업데이트하면 됩니다.

## 현재 상태 요약

- Godot 4 기반의 초기 게임 구조가 구성되어 있습니다.
- 원본 카드와 의뢰 데이터는 `Resource` 파일로 정의하고, 런타임에서는 `ContentCatalog`가 이를 읽어 목록과 ID 맵으로 관리합니다.
- 플레이어가 실제로 보유한 카드는 `GameState.office.owned_cards`를 기준으로 화면에 표시됩니다.
- 좌측에는 플레이어가 보유한 인물 카드가 정렬되어 표시됩니다.
- 우측의 아이콘 버튼으로 인력 사무소, 장비 목록, 소비 카드 목록을 열 수 있습니다.
- 중앙에는 이벤트 또는 의뢰 목록이 표시될 수 있는 영역이 마련되어 있습니다.
- 현재 이벤트 처리는 실제 게임 진행 로직보다 UI 배치와 데이터 연결 확인에 초점을 맞춘 상태입니다.

## 실행 방법

Godot 에디터에서 `project.godot`을 열고 실행하면 됩니다.

현재 저장소에는 로컬 검증용 Godot 실행 파일도 함께 있으므로, 콘솔에서 다음 명령으로 최소 기동 확인을 할 수 있습니다.

```powershell
& '.\Godot_v4.6.1-stable_win64.exe\Godot_v4.6.1-stable_win64_console.exe' --headless --path . --quit-after 1
```

아이콘이나 리소스 import 상태를 새로 맞춰야 할 때는 다음처럼 `--import`를 붙여 실행하면 됩니다.

```powershell
& '.\Godot_v4.6.1-stable_win64.exe\Godot_v4.6.1-stable_win64_console.exe' --headless --path . --import --quit-after 1
```

## 주요 코드 구조

- `scripts/autoloads/content_catalog.gd`
  - `data/cards`, `data/requests` 아래의 카드와 의뢰 리소스를 읽습니다.
  - 카드와 의뢰를 배열 및 ID 맵으로 보관합니다.
- `scripts/autoloads/game_state.gd`
  - 날짜, 주차, 자금, 세금, 보유 카드, 고용 처리를 관리합니다.
  - `starter` 태그가 붙은 카드를 시작 보유 카드로 넣습니다.
- `scripts/core/office_state.gd`
  - 플레이어 사무소의 런타임 상태입니다.
  - 현재 보유 카드, 대기 의뢰, 진행 중 의뢰, 자금과 명성을 담습니다.
- `scripts/core/stat_block.gd`
  - 힘, 민첩, 지능, 매력, 체력 스탯을 담습니다.
- `scripts/cards/card_definition.gd`
  - 인물, 장비, 소비 카드의 원본 정의입니다.
  - 이름, 설명, 등급, 직업, 임금, 스탯, 스킬, 태그 등을 가집니다.
- `scripts/requests/request_definition.gd`
  - 스토리, 일반, 이벤트 의뢰의 원본 정의입니다.
- `scripts/ui/main_screen.gd`
  - 현재 메인 화면 UI 대부분을 코드로 구성합니다.
  - 인물 카드 목록, 이벤트 목록, 인력 사무소, 장비/소비 패널을 그립니다.

## 카드 데이터 흐름

현재 구조는 크게 두 단계로 나뉩니다.

1. 원본 카드 정의
   - `data/cards/*.tres`에 저장된 카드 원본입니다.
   - 예: 인물, 장비, 소비 아이템, 고용 후보.
   - `ContentCatalog.cards`와 `ContentCatalog.cards_by_id`로 접근합니다.

2. 플레이어 보유 카드
   - 실제 화면에 보여주는 카드는 `GameState.office.owned_cards`에 들어 있는 카드입니다.
   - 게임 시작 시 `starter` 태그가 붙은 카드가 자동으로 보유 카드에 들어갑니다.
   - 인력 사무소에서 고용한 인물도 이 목록에 추가됩니다.

아직은 보유 카드가 별도의 인스턴스 타입으로 분리되어 있지 않고, 원본 `CardDefinition`을 직접 참조합니다. 카드별 경험치, 부상, 장비 장착, 강화 상태처럼 개별 상태가 필요해지면 `CardInstance` 같은 별도 런타임 모델을 추가하는 것이 좋습니다.

## 현재 샘플 카드

시작 보유 인물:

- 거리의 중재자
- 밤길 주자

시작 보유 장비:

- 낡은 리볼버
- 암호화 무전기

시작 보유 소비 카드:

- 응급 강장제
- 소문 묶음

인력 사무소 고용 후보:

- 골목 의원
- 장부 해석가

## 현재 UI 상태

- 좌측 인물 카드
  - 접힌 상태에서는 왼쪽 프로필 영역, 중앙 상단 이름, 오른쪽 하단 직업을 보여줍니다.
  - 클릭하면 상세 정보가 펼쳐지고 힘, 민첩, 지능, 매력, 체력, 임금, 스킬, 태그를 보여줍니다.
- 우측 상단
  - 기존 타이틀 텍스트 대신 날짜, 주차, 요일을 보여줍니다.
- 중앙 영역
  - 이벤트 또는 의뢰 목록이 표시되는 자리입니다.
  - 현재는 실제 발생 로직보다 기본 배치와 상호작용 확인용에 가깝습니다.
  - 의뢰 목록의 기본 상태에서는 의뢰 이름만 표시합니다.
  - 의뢰 이름을 누르면 해당 의뢰의 상세 내용과 인물/소비 슬롯이 펼쳐집니다.
  - 임시 `세금 납부` 이벤트가 항상 표시되며, 인물 슬롯과 소비 슬롯을 갖습니다.
  - 세금 이벤트의 소비 슬롯을 누르면 소비 카드 패널이 열리고, 자금 스택 카드를 선택하면 세금 이벤트에 돈이 배치됩니다.
  - 돈이 배치되면 소비 카드 패널은 닫히고, 이벤트 버튼은 `실행`으로 바뀝니다.
  - `실행`을 누르면 현재 주차 세금이 차감되고 이벤트가 완료 상태가 됩니다.
  - 실행 전에는 배치 취소가 가능하며, 실행 후에도 다음 날로 넘기기 전이면 세금 납부 행동을 취소해 환불할 수 있습니다.
- 우측 아이콘 패널
  - 사람 아이콘: 인력 사무소를 열어 고용 가능한 인물을 보여줍니다.
  - 보물상자 아이콘: 보유 장비 카드를 보여줍니다.
  - 물약 아이콘: 보유 소비 카드를 보여줍니다.
  - 현재 보유 금액은 소비 카드 패널 상단에서 별도의 자금 스택 카드처럼 표시합니다.
  - 자금 스택 카드는 실제 소비 가능한 카드가 아니라 현재 금액을 보여주는 UI 전용 카드입니다.
  - 장비와 소비 패널은 우측 영역을 넓게 덮도록 되어 있습니다.
  - 열린 패널은 우측 상단 `X` 버튼 또는 패널 바깥 클릭으로 닫습니다.
  - 아이콘 버튼은 패널 열기와 전환 용도로 사용합니다.

## 현재 주의점

- `docs/architecture.md`의 일부 문장은 초기 작성 당시 기준입니다. 특히 `data/cards`와 `data/requests`가 비어 있다는 설명은 현재 상태와 다릅니다.
- Godot이 생성한 `.uid` 파일과 일부 씬/프로젝트 변경이 로컬 작업 트리에 남을 수 있습니다. 실제로 추적할지 무시할지는 별도로 결정해야 합니다.
- 현재 인력 고용 비용은 임시로 `weekly_wage` 값을 그대로 사용합니다.
- 의뢰와 이벤트는 데이터 구조와 표시 영역만 준비된 상태입니다. 다만 임시 `세금 납부` 이벤트는 자원 배치와 완료 흐름을 시험하기 위해 UI 코드에 직접 구현되어 있습니다.
- 일반 의뢰의 인물/소비 슬롯은 상세 화면에 표시되지만, 실제 카드 배치 처리와 해결 로직은 아직 연결되지 않았습니다.
- 장비 장착과 소비 카드 사용은 아직 UI 목록 표시 단계입니다.
- 저장/불러오기 기능은 아직 없습니다.
- 한국어 UI 문구는 일부만 들어가 있으며, 전체 현지화 기준은 아직 정하지 않았습니다.

## 다음 작업 후보

- `CardInstance` 런타임 모델 추가
  - 원본 카드와 플레이어가 실제로 소유한 카드의 개별 상태를 분리합니다.
  - 장착 장비, 부상, 경험치, 강화, 고용일 등을 저장할 수 있게 합니다.
- 인물 프로필 이미지 구조 추가
  - `CardDefinition`에 프로필 이미지 필드를 추가하고, 현재 이니셜 박스를 실제 이미지로 대체합니다.
- 인력 사무소 확장
  - 후보 리롤, 고용 비용 변동, 랜덤 일반 인물 생성, 고유 인물 조건 해금 등을 추가합니다.
- 장비 장착/해제 흐름 추가
  - 장비 카드를 인물 카드에 부착하고 스탯 보너스가 반영되도록 합니다.
- 소비 카드 사용 흐름 추가
  - 즉시 효과, 기간제 효과, 영구 성장 효과를 구분합니다.
- 일일 이벤트와 의뢰 발생 로직 추가
  - 날짜 진행 시 `available_requests`에 새 의뢰가 들어오도록 합니다.
  - 만료일, 재발 여부, 스토리 체인을 처리합니다.
- 의뢰 해결 시스템 추가
  - 인물과 장비를 배치하고 요구 스탯 또는 스킬을 판정합니다.
  - 성공/실패 결과, 보상, 부상, 평판 변화를 처리합니다.
- 주간 비용 정산 확장
  - 세금과 별도로 인물 임금, 유지비, 벌금 등을 정산합니다.
- 저장/불러오기 추가
  - `GameState`와 `OfficeState`를 저장 가능한 형태로 정리합니다.
- 문서 정리
  - `architecture.md`를 현재 구조에 맞게 갱신합니다.
  - 기능이 추가될 때 이 파일의 업데이트 로그와 다음 작업 목록을 함께 갱신합니다.
